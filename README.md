# MIR Search & RAG

Dual-engine document search and Retrieval-Augmented Generation system for the Modern Information Retrieval final project.

This initial scaffold separates the system into:

- `backend/` - document processing, indexing, retrieval, RAG, and APIs
- `frontend/` - Admin Dashboard and Search interface
- `data/` - local runtime data such as uploads and indexes
- `evaluation/` - retrieval benchmarks and relevance judgments
- `docs/` - architecture, evaluation, and demonstration material
- `scripts/` - setup and maintenance utilities

Implementation will be added incrementally.
